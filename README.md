# WEEKLY 100 — The Ultimate Weekly Productivity Challenge

> **"Own Your Time. Build Your Consistency. Beat Your Best."**  
> *"Don't just count the hours. Make every hour intentional."*

WEEKLY 100 is a modern, full-featured productivity and time-management web application. Users set weekly targets under 100 intentional productive hours (1–99 hrs), distribute them across their chosen active days (1–7 days), schedule time blocks, track sessions with drift-free epoch timers, manage tasks, explore empirical analytics, earn gamified achievements, and protect rest and wellness.

---

## ⚡ Features

- **Core Challenge System:** Configure weekly targets (1–99 hrs), active days, daily allocations, and productivity categories with real-time pacing calculations.
- **Dynamic Dashboard:** Progress cards, 7-day performance overview, productivity summary KPIs, and recent session feeds.
- **Smart Time Tracker:** Non-drifting epoch timestamps, live digital timer, pause/resume/save, task association, break interval segregation (break time never counts toward target), and sound chimes.
- **Distraction-Free Focus Mode:** Prominent digital clock, active task display, and interval pace meter.
- **Daily Scheduler:** Visual calendar with time-blocking, recurring blocks, and automatic non-overlapping hours calculation.
- **Task Management:** Priorities (Low to Important), statuses, due dates, filters, and 1-click focus session launching.
- **Advanced Analytics:** Interactive charts powered by Recharts (Daily planned vs actual bar chart, category donut, multi-week area trend, session duration histogram) and dynamic real-time insights calculated from stored data.
- **Gamification & Achievements:** Productivity levels (*Beginner* to *Master*), milestone badges, confetti celebrations, and all-time personal records.
- **Challenge History & Comparison:** Historical weekly performance archive, side-by-side week comparison modal with delta variance analysis, and 1-click challenge repeat.
- **Smart Planning Assistant & Wellness:** Algorithmic schedule balancing (*Balanced*, *Front-Loaded*, *Weekend-Light*, *Deep Bursts*), 24-hour daily balance visualization, and rest-day safeguards.
- **Customization & Data Portability:** Dark/Light theme toggle, 12h/24h time formatting, JSON backup export and import, demo data loader, and LocalStorage persistence.

## 🛠️ Tech Stack

- **Framework:** React 18 + TypeScript 5
- **Build Tool:** Vite 6
- **Styling:** Tailwind CSS
- **Charts:** Recharts
- **Icons:** Lucide React
- **Celebrations & Audio:** Canvas Confetti + Web Audio API oscillators

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18+)
- npm / yarn / pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/Harshithkumar-sync/weekly-100-hours-challenge-website.git

# Navigate into the project directory
cd weekly-100-hours-challenge-website

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:5173/](http://localhost:5173/) in your browser.

### Production Build

```bash
npm run build
npm run preview
```
